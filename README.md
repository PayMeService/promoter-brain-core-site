# Promoter Brain Core — the guided tour

what the two engines do, how the phases stay apart, how to install, and a plain-language glossary.

Live page: https://constantinshafranski-arch.github.io/promoter-brain-core-site/

The page is one self-contained `index.html` (HTML5, vanilla JS, Three.js and GSAP from cdnjs).
It carries no secrets, hostnames or credentials; the project itself lives in its private repository.
